## 9. Peringatan dan pelajaran
- Jangan menulis nilai kunci/rahasia di catatan; hanya nama variabel. Rahasia tertanam di Edge Functions adalah risiko nyata.
- Rotasi `SUPABASE_SERVICE_ROLE_KEY` mengakhiri semua sesi SIGAP (HMAC); deploy malam hari, beri tahu pengguna.
- Sebelum menonaktifkan kunci legacy, cek klien lain (Android PORTAL BPS, Apps Script SFM, Delego).
- Salinan sandbox sering basi terhadap laptop (`lib/portal/server.ts`, `pendataan/page.tsx`, route foto translok): selalu diff/ambil ulang sebelum menulis. Satu tahap = satu commit = satu deploy (deploy berulang di Railway merugikan).
- MCP Supabase tak punya hapus Edge Function dan DROP INDEX bisa macet: pakai dashboard/SQL Editor.
- Jangan membuat klien Supabase per request di Node; pakai singleton dengan auth dimatikan.
- Region server harus sekota dengan database (Railway dan Supabase Singapura).
- Angka berbeda antar layar umumnya karena definisi/penyebut; beri label, jangan ubah rumus tanpa keputusan.
- SPJ terkunci (88 penugasan, 440 dokumen beku) tak boleh berubah; aturan baru berlaku maju; label foto lama tetap di berkas beku.
- Tautan WA bertoken (/sigap/translok/<token>) sengaja bebas gerbang; N-02 (alamat bertingkat) berisiko tinggi (push, bookmark, simpanan lokal, `jalurWajibApp`).
- Mode "Melihat sebagai" = simulasi; tidak menjangkau translok di server.
- Ukur performa dengan tab terlihat (tab tersembunyi menghentikan prefetch/unduhan). Pesan galat DB jangan dikirim mentah ke petugas.
